# @heightproof/shared

Internal building blocks shared by the [Heightproof](https://github.com/macjayz/heightproof)
SDKs and services: the `HeightproofEvent` schema (Zod), JSON-RPC result normalization and
hashing, redaction helpers, and the content-aware RPC reliability detectors.

You normally do not install this directly; it is a dependency of
[`@heightproof/web3`](https://www.npmjs.com/package/@heightproof/web3) and
[`@heightproof/sdk-node`](https://www.npmjs.com/package/@heightproof/sdk-node). Its API follows
those packages and may change between minor versions while Heightproof is pre-1.0.
